# Source build

See [Development](docs/DEVELOPMENT.md). Supply the separately downloaded official AI Companions **0.4.6 Full ZIP**:

```powershell
python build_auto.py --upstream-archive "<path-to-official-0.4.6-full.zip>"
```

This repository is self-contained apart from declared development dependencies and the separately supplied official archive. Normal users install the release ZIPs with Vortex and do not build the source.
