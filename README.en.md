# AI Companions Community Add-ons

These are optional add-ons for **AI Companions 0.4.6 on Cyberpunk 2077 2.5 / Windows**. Start with the [original Full install and its requirements](https://www.nexusmods.com/cyberpunk2077/mods/35436).

- [Japanese Dialogue and Character Pack](docs/japanese/README.ja.md): Japanese profiles, speech rules, names and game context. Its main documentation is Japanese.
- [Party Conversations and Codex Bridge](docs/codex/README.en.md): companion-to-companion conversations, shared experience and relationship memory, optional bounded replies by V, and an optional Codex CLI provider. The conversation features also work with Gemini and other supported text providers.

Use either add-on or both. For a combined installation, use the matching release pair. Close the game, install the ZIPs in Vortex, enable them and deploy. Normal game startup prepares the selected features. There is no manual `apply.cmd` step.

**Codex CLI sends requests to a cloud service. It is not a local language model.** Model access, quotas and charges depend on your own account, authentication method and service terms. See [Privacy and service usage](docs/PRIVACY.md).
