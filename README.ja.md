# AI Companions向け追加Mod 2本

**本体0.4.6・ゲーム2.5・Windows用の公開候補です。** まず[本体のFull install](https://www.nexusmods.com/cyberpunk2077/mods/35436)と、そのページにある依存Modを導入してください。

- **[日本語会話・人物設定拡張](docs/japanese/README.ja.md)**：人物の紹介・話し方・一人称、固有名詞、AIに渡すゲーム状況を日本語で扱いやすくします。
- **[Party Conversations and Codex Bridge](docs/codex/README.ja.md)**：仲間同士の掛け合いと記憶、必要なときのVの自動返答、任意のCodex CLI接続を追加します。掛け合い機能はGeminiなどでも利用できます。

片方だけでも利用できます。両方使う場合は、このリポジトリの同じ公開世代の2本を組み合わせてください。ゲームを終了し、VortexへZIPを取り込み、有効化して配置を反映すると、次の通常起動時に適用されます。手動の`apply.cmd`は不要です。

**Codex CLIはクラウドへ要求を送ります。PC内だけで推論するローカルLLMではありません。** 利用できるモデル、使用上限、費用は、本人の契約・認証方法・各サービスに従います。[送信する情報と使用量](docs/PRIVACY.md)を確認してください。
