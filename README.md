# AI Companions Community Add-ons

[日本語ガイド](README.ja.md) · [English guide](README.en.md)

[![Source checks](https://github.com/humanpowerplant/cyberpunk-ai-companions-addons/actions/workflows/checks.yml/badge.svg)](https://github.com/humanpowerplant/cyberpunk-ai-companions-addons/actions/workflows/checks.yml)

Two optional add-ons for **AI Companions using Large Language Models 0.4.6**, on **Cyberpunk 2077 2.5 / Windows**.

| Add-on | Start here | Purpose |
| --- | --- | --- |
| **AI Companions 日本語会話・人物設定拡張** | [日本語で導入](docs/japanese/README.ja.md) | Japanese character profiles, speech rules, names and game context. |
| **AI Companions — Party Conversations and Codex Bridge** | [English](docs/codex/README.en.md) / [日本語](docs/codex/README.ja.md) | Companion conversations, optional V replies, and an optional Codex CLI provider. Works with other supported text providers too. |

Install the [original mod](https://www.nexusmods.com/cyberpunk2077/mods/35436) and its requirements first. Use its **0.4.6 Full install for game 2.5**. These small add-ons do not replace the original installation.

The add-ons can be used separately or together. When using both, use the matching release pair. Install, enable and deploy with Vortex; the next normal game startup prepares the selected features. No `apply.cmd` step is required.
