# あとから確認するための判断メモ

対象：日本語1.0.4-rc.2 / Party Conversations and Codex Bridge 1.2.2-rc.2。

**利用者の判断を待って実装を保留した項目は0件です。** 根拠のある不具合は修正し、既存データを守る方針で統合しました。[レビュー記録](REVIEW_20261106.ja.md)に全13件と確認範囲があります。

## こちらで決めたこと

| 論点 | 採用した扱い |
| --- | --- |
| 古い観測に共有オフの情報が混ざる | ファイルは消さず、種別を分離できなければ、その自動観測を送らない。実際に話した内容は会話の記憶として残す。 |
| 時刻オフ時に絶対ゲーム秒が残る | 自動会話ではtimeとlastTalkの両方がオンの場合だけ送る。通常の本体処理は変えない。 |
| Vの反応を増やす | 問いかけを阻む矛盾を除く。質問・Vの返答は必須にせず、回数・待機・期限を維持する。 |
| 壊れた保存設定 | 自動削除や初期化をせず、固定エラーと最小限の退避・再設定の手順を用意する。 |
| 配布上の位置づけ | 実ゲーム・実認証・音声品質を未確認のまま安定版とは呼ばず、同じ世代のRC.2を2本用意する。 |

## 次にプレイするときの確認

これは今回の修正を進めるための承認依頼ではありません。使い心地と安定版扱いの判断に使う、短い実プレイ確認です。

1. 仲間2人の会話からVへ自然な問いが向き、選んだ設定で返答・字幕・任意の音声が出るか。
2. イベントから街中へ戻った後もメニューと会話入力が使え、手動入力で自動会話を中断できるか。
3. 本人の専用Codex認証・使用モデルで会話でき、ゲーム終了後に自動起動したhelperが終了するか。

各項目の詳細は[実プレイ確認表](TESTING.md)へ。ゲーム環境の変更とNexusへのアップロードは、このレビュー作業では行っていません。
