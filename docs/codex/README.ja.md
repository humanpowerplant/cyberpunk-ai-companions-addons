# Party Conversations and Codex Bridge

**1.2.2-rc.1 / AI Companions 0.4.6 / Cyberpunk 2077 2.5 / Windows**

仲間同士が共有した出来事を話し、相手についての記憶・関係を持ち、必要ならVも短く応答する追加Modです。任意でCodex CLIを文章生成に使えます。**掛け合い機能はGeminiなどでも動きます。Codexを選ぶことは必須ではありません。**

## 導入

1. [本体0.4.6のFull install・ゲーム2.5用](https://www.nexusmods.com/cyberpunk2077/mods/35436)と、そのページの依存Modを導入します。
2. ゲームを終了し、ZIPをVortexへ取り込み、有効化して本体より後に配置します。
3. この追加Modの旧版と旧単体 **CodexBridge-Settings** を無効化し、Apply／Deployで反映します。設定メニューはこの新版に統合されています。
4. 通常起動し、**Companion Manager → Conversations** を開きます。手動の`apply.cmd`は不要です。

日本語拡張も使う場合は、今回の組 **日本語1.0.4-rc.1 / Codex・掛け合い1.2.2-rc.1** に揃えます。上書き順は **本体 → Codex・掛け合い → 日本語** です。

## 最初はこの設定から

今使えている文章プロバイダーのまま、仲間を2人招待して移動してみてください。仲間の利用可能性や本体の待機時間で、会話の起き方は変わります。短く試すときだけ **Conversations → Companions speak up → Often (30/hour)** を選ぶ方法もあります。本体の新規既定Normalでは、数分待っても発話が起きない場合があります。試した後は好みの頻度へ戻してください。

| 項目 | 内容・新規設定での状態 |
| --- | --- |
| 仲間の会話記憶 | 届いた会話と観測した出来事をローカルに保存。既定オン |
| 関係更新 | 会話後の評価にもAIを使う。追加要求が発生するため既定オフ |
| Vの自動返答 | オフ／質問されたとき／状況に応じて。既定オフ |
| Vの自動音声 | 自動返答を発声。既定オフ |
| 自動音声のエンジン | 仲間と同じ／Vの個別設定。既定は仲間と同じ |
| Vの性格・一人称・細かさ | 自分のVに合わせて選択・編集 |
| 高頻度・イベント中の発話 | 必要な人が有効にする。要求数や割込みが増える場合がある |

Vの参加を試すなら、まず **質問されたとき・1ラウンド1返答** を推奨します。全発言に反応する設定ではありません。回数上限・待機時間・ラウンドの期限があり、自動会話を延々と続けません。

Vの自動音声は、仲間と同じエンジンでも**V本人の参照音声**を使います。字幕は音声の完成を待つ前に表示し、使える音声経路がなければ字幕のままにできます。手動入力・マイク入力のV音声設定は別に保持します。日本語音声には本体側で対応エンジンと参照音声の準備も必要です。

Vの人物編集はローカルのブラウザー画面で行います。周回の記憶は **V1～V4を手動選択** して分けます。セーブ名から自動判定はしません。保存範囲と追加要求は [データ送信・使用量](../PRIVACY.md) を参照してください。

## 任意：Codexを使う

Codex CLIは**クラウドへ送信するクライアント**です。PC内だけで推論するローカルLLMではなく、契約・認証方法ごとの使用上限や料金に従います。CLI本体と認証は配布しません。[公式の導入案内](https://developers.openai.com/codex/cli/)からCLIを準備してください。

新規導入では、普段の開発用Codexの指示をNPCへ混ぜないよう、専用のCodex設定領域を使います。ゲームフォルダー内の **`red4ext/plugins/AiNpcCodexBridge/Login.cmd` を一度だけ自分で実行** し、Codexを利用できる本人のChatGPTアカウントで公式の認証を完了してください。このbridgeはAPIキー認証を拒否し、環境変数のAPIキーを暗黙に使って課金する方式にはしません。通常のゲーム起動時に、勝手にログイン画面を開いたり認証情報をコピーしたりしません。既存設定からの移行では共有領域の利用が保持される場合があります。状態表示とLogin helperの移行確認を読んでから専用領域へ移してください。

本体の **AI provider → Custom** では、既定の接続先は `http://127.0.0.1:17865/v1`、モデル欄は `codex-default` です。同梱の連携機能がローカル接続トークンを使うため、APIキー欄への手動貼付は不要です。ポートを変更した場合は接続先も同じ値へ変更してください。

**Content packs → Codex Bridge** に使用モデル・推論の設定があります。最初は **CLIの既定モデル・推論自動** を選んでください。旧プリセットは保存済み設定の互換性のために残しますが、本人の契約で使えるとは限りません。任意モデルIDは上級者向けの設定です。非対応モデルや推論量ではエラーを表示し、黙って別モデルには切り替えません。

CLIは専用作業領域とread-only sandboxで動きます。shellや外部連携、指示の読込みを制限しますが、「CLIに存在するすべてのネイティブツールを削除する」という保証ではありません。標準のsandboxが拒否する操作もあります。OpenAI側の規約・制限は引き続き適用されます。

## 更新・削除・確認範囲

更新はゲーム終了後に、旧版を無効化して新版を有効化しDeployします。日本語拡張も使う場合は組を揃えます。保存済みの個人設定・人物編集・記憶・認証を配布既定値で置き換えません。

削除はVortexで無効化してDeployし、次回通常起動します。両追加Modを無効にすれば本体のコードへ戻ります。保存済みの利用者データは残します。

対象はWindows・Vortex・ゲーム2.5・本体0.4.6です。ゲーム2.31、他の本体版、MO2やProtonは未確認です。fixtureの読み込み・解除・通信境界の確認と、実プレイ・音声品質・他PCでの確認は区別しています。[互換性](../COMPATIBILITY.md) / [困ったとき](../TROUBLESHOOTING.md)。

元Mod：Alystria AI。Convai選択肢・元のライセンス・第三者通知を保持します。コード・日本語設定・説明文の作成に生成AIを使用しています。
