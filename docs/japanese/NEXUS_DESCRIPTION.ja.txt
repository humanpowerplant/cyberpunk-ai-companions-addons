[size=5][b]AI Companions 日本語会話・人物設定拡張[/b][/size]

AI Companionsの人物像・話し方・一人称と、AIに渡すゲーム状況を、日本語での会話に向く形へ整える追加Modです。

[b]対象：本体0.4.6 Full install / Cyberpunk 2077 2.5 / Windows・Vortex[/b]
[url=https://www.nexusmods.com/cyberpunk2077/mods/35436]元Modと必要な依存Modを先に導入してください。[/url] この小さなZIPは本体の代わりにはなりません。

[size=4][b]できること[/b][/size]
[list]
[*]796プロフィールの人物紹介・来歴・話し方・知識の範囲を日本語で調整。
[*]人物別の一人称・敬語・呼び方を重視。未確認の一人称を性別だけで決めません。
[*]744プロフィールに5,334本の編集・翻訳による日本語例。公式日本語台本の引用集ではありません。
[*]固有名詞、日本語の検索・文処理、AIに渡す現在のゲーム状況を調整。
[*]「所持金」「お金」「エディー」等を認識し、取得できた現在値を利用。不明な値を0にしません。
[*]日常の頼みへ、本人の都合・条件・反論や頼み返しで応じやすくする共通方針。
[/list]

[b]例文の範囲[/b]：52プロフィールは元の英語例を保持します。ジュディ、ジャッキー、ジョニー、パナム、タケムラ等も含まれます。人物紹介・話し方・一人称ルールの日本語化とは別の範囲です。生成結果や原作再現を完全に保証するものではありません。

[size=4][b]導入は4ステップ[/b][/size]
[list=1]
[*]本体0.4.6のFull install・ゲーム2.5用と依存Modを導入。
[*]ゲームを終了し、このZIPをVortexへ取り込んで有効化。
[*]本体より後に配置し、旧版を無効化してApply / Deploy。
[*]起動後、Companion Manager → Voice AI and microphone → Voice language → Japanese。
[/list]
表示言語はConversations → Interface languageです。回答・音声言語とは別です。既存の個人設定は勝手に初期化しません。手動のapply.cmd実行は不要です。

Codex・掛け合い拡張は任意です。両方使う場合は同じ公開世代の2本を使い、[b]本体 → Codex・掛け合い → 日本語[/b]の順に配置してください。更新・無効化はゲーム終了後にDeployし、次回通常起動で反映します。記憶・人物編集・認証・セーブは削除しません。

[size=4][b]音声・対応範囲[/b][/size]
日本語音声やマイク認識には、本体で対応するエンジンとパックを別途設定します。ゲーム音声、抽出台本、モデル、実行環境、個人のAPIキーや履歴は同梱しません。クラウドを使う場合、会話材料・許可したゲーム状況、選択した音声方式に応じた台詞や参照音声が送信されます。

この公開候補は0.4.6 / ゲーム2.5用です。他の本体版、2.31、MO2、Protonは未確認です。自動fixtureと実プレイは区別し、確認範囲・既知の制限・対処手順を同梱READMEに記載しています。
