# 最初の導入

1. [AI Companions本体](https://www.nexusmods.com/cyberpunk2077/mods/35436)の **0.4.6 Full install・ゲーム2.5用** と、作者指定の依存Modを入れる。
2. ゲームを終了し、この日本語拡張ZIPをVortexへ取り込む。有効にして、本体より後に配置し、Vortexの **Apply／Deploy** を実行する。
3. ゲームを起動する。**Companion Manager → Voice AI and microphone → Voice language → Japanese** を選ぶ。画面の表示言語は **Conversations → Interface language** で選ぶ。
4. セーブを読み込み、会話できるNPCに向いてテキスト会話を試す。標準キーはF6。F4等が別の操作になっている場合はCETのBindingsで割当を確認する。

Codex拡張は任意です。日本語の音声出力・マイク入力には、本体で対応する音声エンジンと認識パックを別途設定します。

既存の会話言語や人物の個人編集を、このZIPが強制的に初期化することはありません。以前の個人編集が優先されている場合は、人物エディターで該当項目を確認してください。

詳しくは [README.ja.md](README.ja.md)。
