# Japanese Dialogue and Character Pack

**1.0.4-rc.1 / AI Companions 0.4.6 / Cyberpunk 2077 2.5 / Windows**

The main documentation is [Japanese](README.ja.md). This optional add-on provides Japanese character profiles, speech rules, names and game context. Its 5,334 Japanese editorial translations and style examples cover 744 of 796 profiles; they are not an extracted game-script collection. The remaining 52 retain their upstream English example field, including Judy, Jackie, Johnny, Panam and Takemura. Their biography and speech-rule translations are still supplied.

Install the [original 0.4.6 Full install for game 2.5](https://www.nexusmods.com/cyberpunk2077/mods/35436) and its requirements first. Close the game, install this ZIP in Vortex, enable it after the original mod and Deploy. Normal game startup applies it; no `apply.cmd` step is needed.

For Japanese replies, select **Companion Manager → Voice AI and microphone → Voice language → Japanese**. Interface language is a separate setting under Conversations. Existing personal choices and character edits are retained.

Codex is optional. If using both add-ons, use this release pair: **Japanese 1.0.4-rc.1 / Party Conversations and Codex Bridge 1.2.2-rc.1**. Recommended conflict order: original mod, Codex/Party add-on, Japanese add-on.

Voice and microphone models are separate original-mod requirements. No game audio, extracted dialogue corpus, account credentials or personal state is included. See [Compatibility](../COMPATIBILITY.md), [Privacy](../PRIVACY.md) and [Troubleshooting](../TROUBLESHOOTING.md).
