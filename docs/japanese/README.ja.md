# AI Companions 日本語会話・人物設定拡張

**1.0.4-rc.1 / AI Companions 0.4.6 / Cyberpunk 2077 2.5 / Windows**

AIに渡す人物設定やゲーム状況を、日本語での会話に向く形へ整える追加Modです。最初の導入は [4ステップの手順](QUICKSTART.ja.md) を参照してください。

## できること

- 796プロフィールの人物紹介・来歴・話し方・知識の範囲を日本語で扱えるようにします。人物ごとの一人称・敬語・呼び方を優先し、未確認の一人称を性別だけで決めません。
- 744プロフィールに5,334本の**編集・翻訳による日本語会話例**を提供します。口調を調整するための例であり、公式日本語台本から集めた引用集ではありません。52プロフィールでは元の英語例を保ちます。ジュディ、ジャッキー、ジョニー、パナム、タケムラ等の主要人物も、この英語例を保持する側に含まれます。人物紹介・話し方・一人称ルールの日本語化とは別の範囲です。
- 人名・地名・組織名、検索・文の区切り、AIに渡す現在のゲーム状況の日本語処理を調整します。
- 「所持金」「お金」「エディー」などの質問を認識し、ゲームから取得できた現在の所持金を使えるようにします。未取得の値を0エディーと扱ったり、NPCが目視で財布を調べたという説明にはしません。
- 日常の頼み事に、本人の判断・都合・反論や頼み返しで応じやすくする会話方針を追加します。重要な原作情報、現在の数値、操作の成立を捏造しないよう指示します。

人物設定はAIに渡す材料です。生成結果、原作らしさ、一人称や固有名詞の完全な一致を保証するものではありません。提供先のモデルや、利用者の個人編集によっても変わります。

## 必要なもの

[AI Companions using Large Language Models](https://www.nexusmods.com/cyberpunk2077/mods/35436) **0.4.6のFull install、ゲーム2.5用** と、本体ページにある依存Modが必要です。小さなUpdate用ZIPだけでは動きません。

Codex拡張は不要です。音声・マイクについては本体でエンジンと言語パックを選んでください。このZIPに音声、モデル、本体Runtimeは含まれません。

## Vortexでの導入・更新

1. ゲームと会話サービスを終了します。
2. ZIPを **Install From File** で取り込み、有効化します。
3. 競合はこの日本語拡張が本体より後になるようにします。Codex拡張も使う場合は **本体 → Codex拡張 → 日本語拡張** とします。
4. 同じ追加Modの旧版を無効化し、Vortexの **Apply／Deploy** で反映します。
5. 次の通常起動時に適用されます。手動の`apply.cmd`は不要です。

両方の追加Modを使う場合は、同じ公開世代の組を使ってください。今回の組は **日本語1.0.4-rc.1 / Party Conversations and Codex Bridge 1.2.2-rc.1** です。古い片方だけを残すと、互換性診断により追加機能を適用できない場合があります。

日本語化を目的にしても、既存の会話言語は勝手に変えません。**Companion Manager → Voice AI and microphone → Voice language → Japanese** を確認してください。メニューの表示言語は **Conversations → Interface language** です。

## 個人編集・日本語音声

人物エディターで保存した個人編集は、本体の優先規則に従って適用されます。更新で自分の人物設定を一括削除する必要はありません。古い英文が残る場合は、該当人物・該当欄の個人編集を確認し、必要な部分だけ戻してください。

日本語の文章設定と、音声の参照・音声認識は別の設定です。文章が日本語でも、Pocketの英語モデルだけで日本語を発声させることはできません。対応言語は本体と使用エンジンの案内を参照してください。クラウド音声を使う場合、台詞や参照音声の送信が伴います。

## 無効化・削除

ゲームを終了し、Vortexでこの追加Modを無効化してDeployし、次回通常起動します。Codex拡張を残せばその機能だけを使い、両方を無効化すれば本体のコードへ戻ります。会話記憶・個人設定・認証・セーブを削除する操作ではありません。

手動展開は更新・削除の取り残しを管理しにくいため、この公開候補ではVortexを推奨します。Mod Organizer 2、Linux/Proton、ゲーム2.31、他の本体バージョンは確認対象外です。

## 公開範囲と確認範囲

ゲーム音声・抽出台本・個人の会話履歴・World rules・APIキーは配布しません。コードとデータの組合せ、単独・併用・解除は自動fixtureで確認します。実プレイ、他PC、多数の他Modとの互換性とは区別しています。[確認範囲](../COMPATIBILITY.md)と[困ったとき](../TROUBLESHOOTING.md)を参照してください。
