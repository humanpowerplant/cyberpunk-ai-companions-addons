# 公開画像とスクリーンショット案

`titlecards/` に、独自の図形・文字で作ったカバーPNG、サムネイルPNG、編集用SVGを用意します。ゲーム画像、キャラクター絵、公式ロゴ、俳優音声は使いません。図には「実ゲーム画面ではない」と明記します。NexusではAI Mediaの開示対象として扱います。

| 優先 | 撮りたい実ゲーム画面 | 伝えること | 公開用キャプション案 |
| --- | --- | --- | --- |
| 1 | 招待した仲間2人と歩き、相手へ向けた掛け合い字幕が出た場面 | Vだけを相手にする会話から、仲間同士の会話へ | 「一緒に見た出来事を、仲間同士で話す」 / “Companions react to shared experiences.” |
| 2 | Vに向けた質問の後、Vの字幕が出た場面 | Vの参加は任意・条件付き | 「必要なときだけ、Vも会話へ」 / “Optional, bounded replies by V.” |
| 3 | Conversationsの追加設定とVの編集画面 | 頻度・回数・性格・一人称を自分で選べる | 「会話の量とVらしさを調整」 / “Choose V's personality and participation.” |
| 4 | 日本語の人物エディター：人物像・話し方・一人称・編集例 | 日本語化が人物設定へ届くこと | 「一人称と話し方を、人物ごとに」 |
| 5 | Codex BridgeのCLI default / automatic、正常な接続状態 | 固定の特殊モデルを要求しない導線 | “Use your own Codex CLI account and supported model.” |
| 6 | 音声準備中に字幕が先に表示され、処理HUDが見える場面 | 待ち時間の見通しと字幕先行 | 「音声を待つ前に字幕を表示」 / “Captions before voice readiness.” |
| 7 | Vortexで本体と追加Modの有効状態・順序 | 小さな追加Modで本体が必要 | 「本体の後に配置。手動apply不要」 |

## 撮影の条件

- 安定した街中、服を着た人物、読める字幕を中心にする。過度な露出や暴力が入った画像を通常のカバーに使わない。
- APIキー、認証画面、ローカルトークン、メールアドレス、利用者名を含むパス、個人的な会話を撮らない。
- 合成の台詞を実際の出力に見せかけない。再現例・概念図・実ゲーム写真の区別を付ける。
- 比較画像は同じNPC、場面、設定、質問を使い、モデルが違う場合は明記する。1回の作例を常時の品質保証にしない。
- ゲーム内の他Modが見える場合は、この追加Modの機能であると誤解させない。衣装・カメラ・HUD等のクレジットも必要に応じて添える。

30～45秒の紹介動画なら「仲間2人の短い掛け合い → Vへの問い → Vの短い返答 → 設定画面」の順が分かりやすいです。無関係な会話を長く並べず、実際の設定と待ち時間が伝わる長さにします。

## 再レンダリング

必要なときだけ、Pillowと日本語を描けるシステムフォントを用意して `python tools/render_media.py --font <font-file>` を実行します。フォントファイル自体は配布しません。通常のMod導入にはPillowもこのツールも不要です。
