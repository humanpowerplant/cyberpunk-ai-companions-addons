[size=5][b]AI Companions — Party Conversations and Codex Bridge[/b][/size]

仲間同士が、その場の出来事やVの行いについて話し、相手についての記憶を持つ追加Modです。必要なときだけVも短く応答する設定と、任意のCodex CLI連携を追加します。掛け合い機能はGeminiなどでも利用できます。

[b]本体0.4.6 Full install / Cyberpunk 2077 2.5 / Windows・Vortex用[/b]
[url=https://www.nexusmods.com/cyberpunk2077/mods/35436]本体と必要な依存Modを先に導入してください。[/url]

[list]
[*]仲間同士の掛け合いと共有経験の記憶。
[*]任意の関係更新と、質問されたとき/状況に応じたVの自動返答。
[*]Vの性格・一人称・細かさ、返答回数と待機時間。
[*]V本人の参照を使い、仲間と同じエンジンで自動音声。
[*]字幕先行、返答長の調整、処理状況HUD、高頻度・イベント中発話の選択。
[/list]
新規では関係更新・Vの自動返答・自動音声はオフ。既存の明示設定は保持します。自動会話や関係評価はAI要求を増やし、頻度は保証回数ではありません。

ゲームを終了してVortexで本体より後に有効化しDeploy。旧版と旧CodexBridge-Settingsは無効化します。次回通常起動で反映され、手動apply.cmdは不要です。追加設定はCompanion Manager → Conversations。日本語拡張も使う場合は同じ世代へ揃え、本体 → Codex・掛け合い → 日本語の順にします。

Codexを選ぶ場合のみ公式CLIと本人のChatGPTログインが必要です。ゲーム内のred4ext/plugins/AiNpcCodexBridge/Login.cmdを一度実行し、専用領域で認証します。APIキー認証は使いません。Custom providerの既定接続先はhttp://127.0.0.1:17865/v1、モデル欄はcodex-default。モデル・推論はContent packs → Codex BridgeでCLI既定/自動から試してください。

[b]Codexはクラウドへ送る方式で、ローカルLLMではありません。[/b] 利用枠・費用・保持条件は本人の契約とサービスに従います。会話材料・許可したゲーム状況が送信され、本体で画像を有効にした場合はゲーム画像、クラウド音声では台詞や参照音声も送信対象です。認証・受信上限・取消・read-only sandbox等を備えますが、同一Windowsアカウントの悪意あるソフトまで隔離する保証ではありません。

公開候補の確認範囲と導入・更新・削除・対処手順は同梱READMEへ。元Mod：Alystria AI。Convaiと元ライセンス・第三者通知を保持。ゲーム音声・抽出台本・モデル・Runtime・個人認証・履歴は同梱しません。コード・日本語設定・文書・画像レイアウトに生成AIを使用しています（AI-Generated Content / AI Media）。
